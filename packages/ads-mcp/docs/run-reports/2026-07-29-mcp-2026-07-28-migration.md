# ADS MCP 2026-07-28 migration report

Date: 2026-07-29
Branch: `agent/ads-mcp-2026-07-28`

## Result

The local release candidate now uses the MCP TypeScript SDK v2 split packages and one
`serveStdio` binary for both protocol eras. The public tool contract remains exactly
`ads_render`, `ads_evaluate`, and `ads_trace`.

The package also advertises the stable MCP Apps extension and serves a self-contained inline
evidence review at `ui://ads/review`. Run handles remain filesystem-backed application identifiers
and recover across fresh MCP client, server, and service instances.

No npm publication, Registry write, Git push, public-site change, or deployment occurred.

## Architecture decisions

- Protocol: support legacy `initialize` and modern `server/discover` with MCP `2026-07-28`.
- SDK: replace `@modelcontextprotocol/sdk` v1 with `@modelcontextprotocol/client` and
  `@modelcontextprotocol/server` v2.
- State: preserve `<root>/.ads/runs/<runId>` as the durable run spine; never depend on an MCP
  session identifier.
- Apps: advertise `io.modelcontextprotocol/ui` with the required MCP App MIME type, attach
  `_meta.ui.resourceUri` to the three tools, and keep meaningful text/structured fallbacks.
- App lifecycle: implement `ui/initialize`, `ui/notifications/initialized`, tool result and
  cancellation notifications, host context changes, server tool/resource proxy calls,
  size changes, model-context updates, ping, and teardown over JSON-RPC `postMessage`.
- Tasks: do not advertise `io.modelcontextprotocol/tasks`. Current calls are bounded and
  synchronous; the deprecated core Tasks API is not reused.
- Auth: keep local stdio unauthenticated. A remote transport remains blocked on current
  OAuth/OIDC implementation.
- Persistence: local recovery is verified. Hosted or replicated operation remains blocked on a
  shared durable store and concurrency controls.

  CLI acceptance passed independently.
- The first Claude Desktop trace dispatch stalled before reaching the server. Restarting Desktop
  recovered a trace-only call against the durable run handle.
