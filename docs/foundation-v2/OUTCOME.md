# Agentic Design System foundation v2

## Goal

Create a reviewable foundation release that makes the utility and expressive profiles explicit, records anti-agent visual evidence from the rendered page, restores Pawprint hash-state capture, and closes the installed workflow gaps.

## Success means

- The utility and expressive profiles have machine-readable weights and eligibility rules
- One canonical contract defines deterministic blockers, rendered advisories, typography defaults, icon policy, status treatment, and narrow data exceptions
- Evidence format 2 records computed border edges, one-edge shadow candidates, text transforms, typography outliers, symbol-only controls, status-dot candidates, divider counts, and colon candidates
- The new measurements remain report-only until fixture precision is established
- Pawprint renders distinct default, loading, empty, and error states from direct hash links
- Installed agents receive routing, presets, and path-correct executable commands
- Public package language does not assume a named maintainer or user

## Earliest weak layer

The visual foundation and component contract are the earliest weak layers. Existing capture proves runtime behavior but cannot yet express the new visual contract, while the current scoring and font guidance push utility work toward novelty.

## Verification

- Focused contract and capture fixture tests show an observed red state before implementation and green after implementation
- A browser test deep-links into all four Pawprint states
- A rendered Pawprint packet contains distinct screenshots and evidence format 2
- The five-agent installation matrix executes the installed public commands
- The existing frozen v1.3.1 packet verifies unchanged
- The demo build, accessibility checks, and relevant smoke tests pass

## Stop when

Stop at a local, tested, screenshot-reviewed branch. Do not begin the broad public-demo migration, activate heuristic blockers, create new example routes, publish, merge, or deploy.
